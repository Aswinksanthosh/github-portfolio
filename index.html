Project 01

Calendar Automation & Data Dashboard

A production-style automation system — Jan 2025 to Present

Python n8n Google APIs PostgreSQL Docker JavaScript OAuth 2.0 Webhooks

A fully automated personal calendar assistant that converts all-day tasks into scheduled timed events using rule-based logic. Built to manage 50+ weekly tasks, the system integrates Google Calendar, Google Sheets, and a live PostgreSQL dashboard — all containerized with Docker.

  • Scheduling engine finds free slots in 15-minute increments, respecting buffers, time windows, and custom rules
  • Bidirectional CRUD sync between Google Sheets and Calendar — changes in either system propagate instantly
  • Smart dependency engine chains events (e.g. "Gym must be after Work") and reshuffles automatically
  • Webhook handler lets users finish, postpone, or compress events with one click inside Calendar descriptions
  • Real-time PostgreSQL dashboard visualizes automation metrics; full stack containerized with Docker
  • Unit-tested with pytest; full version control with Git throughout development
System Architecture: [Timer / Manual Trigger] | [Google Calendar] <--> [Google Sheets] | [CRUD Sync Node] — syncs all-day tasks with sheet configs | [Scheduling Engine] — finds free slots, handles priorities | [Dependency Engine] — enforces chains, buffers, avoid-rules | [Webhook Handler] — listens for FINISH / POSTPONE / COMPRESS
